# React Machine Coding Projects

This repository contains a collection of small React and JavaScript UI projects built for learning, practice, and frontend component development. Each folder is a separate mini-project focused on a specific UI pattern or interaction.

## Project Overview

The workspace includes several Vite-based React applications that demonstrate:

- Search/autocomplete functionality
- File explorer UI
- Form validation patterns
- Pagination behavior
- Progress indicators
- Tabbed form interfaces
- JavaScript-based form handling

## Included Projects

### 1. Autocomplete Searchbar
Location: `autocomplete-searchbar/`

A React app that demonstrates a searchable input with suggestion/autocomplete behavior. It is useful for learning controlled inputs, filtered lists, and UI interactions.

### 2. File Explorer
Location: `file-explorer/`

A file and folder explorer interface built with React. This project focuses on nested data rendering, folder expansion, and tree-like navigation.

### 3. Form Validation
Location: `form-validation/`

A registration or form validation example using React. It demonstrates input validation, error handling, and user feedback in a modern React UI.

### 4. JavaScript Form Validation
Location: `form-validation-javaScript/`

A plain JavaScript-based form validation example. This project is useful for comparing native JavaScript form handling with React-based validation patterns.

### 5. Pagination
Location: `pagination/`

A reusable pagination UI that demonstrates page navigation and list partitioning. This is good practice for data display and pagination logic.

### 6. Progress Bar
Location: `progrecce-bar/`

A simple progress bar component project showing how to represent loading or completion states visually.

### 7. Tab Form
Location: `tab-form/`

A multi-tab form interface with different panel sections such as profile, interests, and settings. This app shows how to organize form sections into tabs and manage state across views.

## Getting Started

Each folder is an independent project and should be run separately.

### Install dependencies

```bash
cd autocomplete-searchbar
npm install
```

Or for any other project folder:

```bash
cd form-validation
npm install
```

### Run a project locally

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Running the Whole Workspace

This repository is not configured as a single app. Each project is a standalone mini-app, so you typically run one folder at a time.
